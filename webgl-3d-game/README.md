# 星际穿越 · 3D 无尽跑酷

网页版 3D 跑酷游戏，**自研透视投影 3D 引擎，零外部依赖**（不依赖 WebGL / 任何 CDN），单页打开即玩。

## 文件
- `index.html` — 页面骨架 + 霓虹 UI
- `game.js` — 3D 引擎与全部游戏逻辑

## 玩法
- `A` / `D`（或 ← →）左右移动；手机左右拖动
- `空格` 冲刺（消耗护盾能量）
- 躲开**红色陨石**，吃**蓝色能量块**（回护盾 +55 分）
- 速度随里程递增，撞到陨石任务结束

## 特性
- 自研 3D：星星 / 跑道梯形透视 / 飞船 / 障碍全部经相机投影渲染
- 护盾能量条、碰撞抖动、速度线、引擎光焰脉动
- 结算画面 + 最高分本地保存（localStorage）
- 响应式，桌面与手机均可玩

## 本地运行
直接双击 `index.html`，或用任意静态服务器：
```
python3 -m http.server 8000
```
