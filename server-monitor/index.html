stats.py · 词频 + 按行数统计

单文件 Python 脚本。原有能力：统计一段文本里每个词出现的次数；本次新增：按行数统计。无第三方依赖，Python 3.6+ 直接运行。

本次新增 · 按行数统计

字段说明
total_lines总行数（含空行）新增
non_empty_lines非空行数新增
blank_lines空行数（仅空白字符）新增
code_lines有效代码行（非空且非注释）新增
comment_lines注释行（以 # 开头）新增
max_line_len最长行字符数新增
avg_line_len平均行长（按总行数）新增

用法

# 词频（原有）
python3 stats.py "the quick brown fox jumps over the lazy dog the fox"
python3 stats.py -f 文章.txt
cat 文章.txt | python3 stats.py

# 按行数统计（新增）
python3 stats.py -l -f 文章.txt        # 词频 + 行数统计
python3 stats.py --lines-only -f stats.py   # 只输出行数统计

# JSON（含 line_stats）
python3 stats.py -j -l -f 文章.txt

输出示例（--lines-only）

—— 按行数统计 ——
总行数        : 11
非空行数      : 7
空行数        : 4
有效代码行    : 4
注释行        : 3
最长行字符数  : 27
平均行长      : 6.9

参数

  • -f 文件 从文件读取文本
  • -n 10 只显示前 10 个高频词
  • -c 区分大小写（默认不区分）
  • -j 输出 JSON，便于程序调用
  • --no-bar 不显示条形图
  • -l / --lines 同时输出按行数统计 （新增）
  • --lines-only 只输出按行数统计 （新增）
