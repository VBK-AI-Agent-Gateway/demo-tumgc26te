# 荣威RX5 网页版车机系统（rx5-ivis）使用说明

## 概览
本项目是仿荣威 iVIS 智能座舱的网页版车机 UI 演示，10.4" 竖屏中控自适应（也兼容普通手机竖屏），
对标斑马智行 / 洛神智能座舱的交互逻辑，卡片化借鉴理想 / 小鹏。

## 技术栈
- Vue3 (CDN 全局构建)
- TailwindCSS（CDN，可移除，样式主要走自写 CSS）
- 纯 HTML5 + 原生 CSS 变量主题切换

## 交互要点（安全优先）
- 顶部挡位条 P/R/N/D 可点击切换，切到 **D** 自动把车速拉起并提示「行车中，娱乐受限、导航优先」；
  切回 **P** 回到驻车态，车速归 0。
- 多媒体在 D 挡弹出红色安全条限制视频，音乐仍可用；P 挡解锁全部娱乐。
- 主页的导航卡在 D 挡自动高亮（「D 挡·导航优先展示」）。
- 底部 Dock 常驻快捷入口，切页用 page 过渡动画（transform + opacity 0.32s）。
- 语音助手：Dock「语音」或顶部 mic 唤出全屏语音层；输入你的指令，
  系统按关键词匹配执行（打开空调/导航去公司/播放音乐/调到二十三度/打开座椅加热等）。
- 弹窗均为轻量 Toast（顶部小胶囊），悬浮面板不遮挡导航。

## 快速启动
浏览器直接打开 index.html 即可（需联网加载 Vue3/TailwindCDN）。
在桌面预览可用浏览器开发工具切换到 iPhone/Android 竖屏尺寸 或窗口 < 900px 自动单列布局。

## 与真实车机的差异
纯前端 Mock，无真实 CAN 总线/ADAS 数据。地图底图为 CSS 绘制的示意道路网 + 模拟车辆小车实时定位。
媒体播放只是计时进度条，无音频流。所有数据在内存中，刷新即重置。
