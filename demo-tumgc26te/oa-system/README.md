# 标准OA协同办公系统

纯前端单页应用（HTML/CSS/JS），无构建依赖，可直接静态托管。

## 功能模块
- 登录认证（演示账号: admin / zhangsan / lisi，密码任意）
- 工作台（待办、统计、最新公告）
- 考勤管理（出勤统计与明细）
- 请假 / 出差 / 报销 / 办公用品采购：申请提交 + 状态跟踪
- 审批中心（通过 / 驳回，按角色与部门权限过滤）
- 公告通知（查看、发布、置顶）
- 通讯录、系统管理（权限矩阵、数据概览、重置）

## 运行
直接打开 `index.html`，或将本目录部署到任意静态托管。
数据存储于浏览器 `localStorage`。
